# Силовой периметр СЗФО × продукты Сбера — аналитический дашборд

Интерактивная HTML-страница с оценкой потенциала продаж продуктов Сбера
государственным силовым ведомствам Северо-Западного федерального округа.

> ⚠️ **Демонстрационная модель.** Оценки рассчитаны на основе публикаций прессы
> и экспертной калибровки. Не являются офертой, не содержат персональных данных
> и не заменяют коммерческую проработку.

## Что внутри

- **Периметр:** 12 госсиловых ведомств СЗФО (МВД, Минобороны/ВМФ, ФСИН, ФССП,
  ФТС, Росгвардия, МЧС, ФСБ, СК, прокуратура). Блок ОПК исключён.
- **Продукты:** 10 классических (зарплатные проекты, военная ипотека,
  кредиты, эквайринг госплатежей, GigaChat, облако, ИБ) + 5 экосистемных
  (СберПрайм, Спасибо, Самокат/Купер, СберЗдоровье, СберМобайл).
- **Скоринг:** две модели — `core` (прямая продажа) и `eco` (бенефит через
  соцпакет), результат 0–100 с разбивкой по факторам.

## Разделы дашборда

1. KPI-панель (ведомства, возможности, приоритетные, средний скоринг)
2. Топ-15 возможностей продаж (горизонтальные бары с тегами CORE/ECO)
3. Матрица «ведомство × продукт» (тепловая карта скоринга)
4. Разбор по каждому ведомству (карточки с продуктами, конкурентами, инсайтами)
5. Фильтр по типу модели (все / классические / экосистема)

## Локальный запуск

Страница самодостаточна — данные зашиты inline. Просто откройте `index.html`
в браузере или поднимите статический сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Пересборка данных

Дашборд генерируется из `report.json` (лежит в репозитории как `data.json`).
Логика модели и генератор — в основном проекте (`config.py`, `analyzer.py`,
`orchestrator.py`, `build_html.py`).

## Деплой

Автоматический через GitHub Actions (`.github/workflows/deploy.yml`) при push
в `main`. В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

## Структура

```
index.html   — самодостаточный дашборд (данные + стили + JS inline)
data.json    — исходный результат прогона модели
README.md    — этот файл
.github/workflows/deploy.yml — автодеплой на GitHub Pages
```
